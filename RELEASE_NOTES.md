# Bully Starter Kit v0.4.0 Release

Первый стабильный релиз после серии реальных тестов на Windows 10.

## Главное

- проверенная связка **SilentPatch + Essential Fixes + One Percent Better**;
- рекомендуемые **60 FPS**;
- отполированный двухколоночный интерфейс RU/EN на системном Segoe UI;
- плавный переключатель **Авто / Slow Download** с двумя отдельными сценариями загрузки;
- **Авто**: Nexus API + Premium с прямой загрузкой;
- **Slow Download**: официальный бесплатный Nexus-поток без обязательного API-ключа;
- автоматический переход Auto → Slow Download при `403`/отсутствии ключа;
- отдельные безопасные установщики ZIP для Essential Fixes и One Percent Better;
- резервная копия и автоматический rollback;
- финальный вопрос про встроенный русский язык Bully;
- новый экран успешной установки с кнопкой **Запустить Bully**;
- GitHub Actions, SHA-256, Credits и двуязычная документация.

## Nexus Mods

Пользователь выбирает режим прямо в интерфейсе. **Авто** рассчитан на API + Premium. **Slow Download** работает без обязательного API key: Starter Kit открывает официальную страницу Files, пользователь нажимает Manual Download → Slow Download, после чего приложение автоматически находит и проверяет ZIP.

## Проверено

Рабочая beta.10 была протестирована на запуск Bully и 60 FPS. Release сохраняет эту установочную логику, добавляя публичный no-API режим и обновлённый интерфейс.
