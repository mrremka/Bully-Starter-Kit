# Русский язык в Bully

Bully Starter Kit не распространяет отдельный сторонний русификатор.

## Как работает опция

После установки выбранных модов программа задаёт отдельный вопрос: **«Включить русский язык в самой Bully?»**

- **Нет** — игра остаётся без изменений языка.
- **Да** — для поддерживаемой Steam PC-версии Starter Kit находит `12200_install.vdf`, создаёт его резервную копию и меняет языковой код встроенной локализации на `1049`.
- Интерфейс и субтитры игры становятся русскими; озвучка остаётся английской.
- Если ожидаемый файл/структура не найдены, Starter Kit не пытается «угадать» и не правит файл: пользователь получает сообщение, а моды остаются установленными.

## Steam

После активации встроенной локализации обычно следует оставить язык Bully в свойствах Steam на **English**, чтобы Steam не перезаписал используемую конфигурацию. В самой игре включите субтитры.

## Rockstar / retail

Для изданий, где `12200_install.vdf` отсутствует, Starter Kit не меняет игровые файлы автоматически. Для классической PC-версии Rockstar выпускала официальный патч 1.200. Для языка используйте только локализацию, соответствующую вашему конкретному изданию; Starter Kit не пытается подменять файлы неизвестной retail/Rockstar-сборки.

- Rockstar Support — Bully Patch 1.200: https://support.rockstargames.com/articles/4wnaaY3gRvw1388h0yH0OF/bully-scholarship-edition-patch-1-200-pc-only

## Откат

Изменение языка выполняется через ту же backup-систему, что и моды. **ВОССТАНОВИТЬ / Restore Backup** возвращает предыдущий `12200_install.vdf`.
