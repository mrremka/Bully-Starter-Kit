# Nexus Mods: бесплатные аккаунты

Bully Starter Kit **не обходит ограничения Nexus Mods**.

Для бесплатного аккаунта рекомендуется режим **Slow Download**. Starter Kit открывает официальный файл Nexus, после чего пользователь нажимает `Manual Download` → `Slow Download`. Программа сама находит ZIP в системной папке «Загрузки», проверяет его и продолжает установку.

Если пользователь выбрал **Авто**, но Nexus возвращает `403 Forbidden`, Starter Kit не завершает установку с ошибкой: интерфейс переключается на Slow Download и продолжает официальный бесплатный сценарий.

Если браузер сохраняет файлы не в стандартную папку, в окне Slow Download можно выбрать ZIP вручную.
