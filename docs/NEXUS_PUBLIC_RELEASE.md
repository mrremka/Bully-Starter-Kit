# Nexus Mods и публичный релиз

Bully Starter Kit v0.4.0 предлагает два режима загрузки Nexus-модов прямо в интерфейсе.

## Авто

- использует Nexus API для определения актуального файла;
- скачивает файл напрямую, когда Nexus разрешает такую загрузку;
- рассчитан на Premium + API key;
- если Nexus возвращает `403` или ключ отсутствует, Starter Kit автоматически переключается на Slow Download.

## Slow Download

- не требует API key;
- открывает официальную страницу нужного мода на Nexus Mods;
- пользователь нажимает **Manual Download → Slow Download**;
- Starter Kit отслеживает папку «Загрузки», проверяет ZIP и продолжает установку.

Оба режима используют только официальные источники. Проект не обходит ограничения Nexus и не зеркалирует сторонние моды в GitHub Releases.
