# Участие в разработке Bully Starter Kit

Спасибо за помощь проекту.

## Перед Pull Request

- Сохраняйте default-пресет близким к оригинальной Bully: фиксы + умеренный Vanilla+.
- Не коммитьте и не зеркалируйте сторонние архивы без явного разрешения автора/лицензии.
- Для каждого нового компонента указывайте автора и оригинальный источник.
- Любое изменение файлов игры должно проходить через бэкап/rollback-механику.
- Не помещайте API-ключи, cookies, токены и другие секреты в код, логи, скриншоты и fixtures.
- Новые пользовательские строки добавляйте одновременно в `locales/ru.json` и `locales/en.json`.

## Проверка изменений

Перед PR на Windows запустите:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-Project.ps1
```

Для изменений установщика желательно проверить: чистую установку, повторную установку, неверный Nexus-ключ/ошибку загрузки, автоматический rollback, ручной Restore и ответ Да/Нет на вопрос о русском языке Bully.

## Визуальный стиль

Используйте текущую графитово-жёлтую стилистику. Основной путь установки должен оставаться очевидным, а авторы/источники сторонних компонентов — доступными из интерфейса и README.
